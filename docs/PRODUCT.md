# PRODUCT — Deskling

## 한 줄 정의

AI 코딩 에이전트 **세션 하나가 직원 한 명**인 작은 아이소메트릭 픽셀 사무실을 바탕화면에 박아 두고,
직원들이 실제 이벤트대로 일하고·손 흔들고·쉬고·퇴근하는 모습으로 "지금 누가 무엇을 하는지"를 보여주는 관찰용 위젯(ADR-025).

## 문제

AI 코딩 에이전트는 긴 작업을 터미널이나 다른 창 뒤에서 수행한다. 요즘은 Claude Code·Codex 세션을 여러 개 동시에 띄워 둔다. 사용자는

- 어느 세션이 아직 일하는지, 끝났는지, 승인을 기다리는지 알기 위해 창을 계속 전환하고,
- 여러 세션 중 하나가 승인 대기나 오류에 걸린 것을 늦게 발견해 시간을 잃는다.

## 해결

바탕화면에 박힌 작은 투명 창(기본은 다른 창 아래, "위에 띄우기"로 변경 가능, ADR-021)에 사무실 하나를 보여준다.

- 세션이 시작되면 직원이 문으로 들어와 빈 책상(8개)에 앉는다. 세션이 끝나면 문으로 나간다.
- 직원은 **자기 세션의 사실만** 보인다: 생각·코딩·웹·터미널·파일 작업은 책상에서(모니터에 상태 화면),
  승인 대기면 일어나 손을 흔들고(호박색), 오류면 머리를 감싸고(붉은 주황), 성공하면 3초 환호한다.
  대기 중이면 라운지(커피머신·정수기·소파·창가·화분)로 가서 쉰다.
- 장면 위 요약 말풍선이 사무실 전체를 센다("2명 일하는 중 · 1명 승인 대기"). 승인 대기·오류인 직원은 그 아래 알림 줄이 이름으로 알린다.
- 완료한 작업이 쌓이면 사무실이 자란다(포스터 → 화분 → 줄 조명 → 러그 → 책장 → 트로피).

## 사용자

- Claude Code·Codex 같은 AI 코딩 에이전트를 로컬에서, 여러 세션 동시에 돌리는 개발자.
- 에이전트를 띄워두고 다른 일을 하면서 상태만 가끔 곁눈질하고 싶은 사람.

## 제품 원칙

1. **관찰만 한다.** 에이전트를 조작하지 않는다. 승인 버튼도, 명령 입력창도 없다. 훅은 결정을 내리지 않는다.
2. **사실만 보여준다.** 실제 이벤트가 말한 것만 표시한다. 진행률 바, 예상 시간, "아마 ~하는 중" 같은 추측은 없다.
   라운지에서 쉬는 것은 "대기"라는 사실의 표현이고, 직원끼리 잡담을 지어내지 않는다.
3. **비밀을 모른다.** 프롬프트·코드·경로·명령·키 같은 내용은 애초에 받지도 저장하지도 않는다. 훅은 세션 id·이벤트 종류·도구 범주만 보낸다.
4. **방해하지 않는다.** 작고, 대부분 투명하고, 바탕화면 층에 있고, 움직임을 줄일 수 있다.
5. **Provider 중립.** 특정 에이전트에 묶이지 않는 이벤트 규격(`AgentEvent` v3)을 쓰고, provider별 변환은 adapter가 맡는다.
   UI는 `source.kind`로 직원의 모습·이름표만 고른다.
6. **데모는 데모라고 말한다.** 가짜 데이터로 동작할 때는 항상 DEMO 배지를 보인다.

## 범위

### 지금 되는 것 (M0–M13)

- Tauri 2 투명 창(640×440, S/M/L), 바탕화면 층·Dock 없음, 드래그·투명도·위에 띄우기·모션 설정
- 직접 만든 SVG 아이소메트릭 픽셀 사무실과 직원 모습 3종(Claude·Codex·에이전트), 격자 A* 걷기
- 11개 시각 상태의 포즈·이모트·모니터 화면·문구, 세션 사이 대화(`session.message`: 말풍선·편지)
- 세션별 에너지·화남(보고된 토큰·컨텍스트 숫자가 있을 때만), 사무실 성장(경험치 → 소품 6종)
- 활동 패널: 사무실 묶음, 세션 목록, 최근 활동, 토큰 예산, 보기(자동/실제/데모), 데모 시나리오
- **실제 연결:** Claude Code(ADR-024), Codex(ADR-026) — 각자의 훅 → Unix 소켓 → Rust 엄격 검증 → 앱. 설치는 사용자 동의 후에만
- 결정적 데모 "사무실 하루"(Claude 3 + Codex 2 + 에이전트 1)와 `core`·`tour`·`life` 시나리오

### 아직 아닌 것

- Hermes Agent 등 다른 에이전트의 실제 연결(규격상 `hermes` 종류는 있고 데모로만 보인다)
- Claude Code·Codex의 토큰·컨텍스트 수치(transcript를 읽지 않으므로 에너지·화남은 표시 없음)
- 메뉴 막대 아이콘, 창 위치 기억, 클릭 통과 모드, 전체 화면 Space 위 표시(백로그)

### 하지 않는 것 (Non-goals)

- 에이전트 제어, 권한 승인, 명령 실행
- 대화 내용·reasoning·파일 diff·명령 뷰어
- 비용·진행률 대시보드, 남은 시간 추정
- Windows/Linux 정식 지원 (macOS 우선)

## 성공 신호

- 사용자가 창을 전환하지 않고도 "몇 명이 일하는 중이고, 누가 승인 대기·오류인지"를 1초 안에 구분한다.
- 새 Claude Code·Codex 세션을 열면 직원이 들어오고, 닫으면 나가는 것을 보고 세션 수를 안다.
- 데모 모드와 실제 모드를 혼동하지 않는다.
- 보안 리뷰에서 민감 데이터가 UI·로그·저장소·훅 레코드에 남는 경로가 발견되지 않는다.
