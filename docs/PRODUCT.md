# PRODUCT — Deskling

## 한 줄 정의

AI 에이전트가 지금 **무엇을 하고 있는지**를 바탕화면에 박힌 밝은 아이소메트릭 픽셀 미니룸과 그 안에서 사는 펫 헤르메스로 보여주는 관찰용 위젯. 대기 중의 일상은 펫 자신의 생활일 뿐 에이전트에 대한 주장이 아니며, 에이전트 상태는 실제 이벤트만 반영한다(ADR-019, ADR-020).

## 문제

AI 코딩 에이전트는 긴 작업을 터미널이나 다른 창 뒤에서 수행한다. 사용자는

- 에이전트가 아직 일하는 중인지, 멈췄는지, 승인을 기다리는지 알기 위해 창을 계속 전환하고,
- 승인 대기나 오류를 늦게 발견해 시간을 잃는다.

## 해결

바탕화면에 박힌 작은 투명 창(기본은 다른 창 아래, "위에 띄우기"로 변경 가능, ADR-021)에 에이전트의 **현재 상태 하나**를 헤르메스의 행동·이모트·짧은 텍스트로 보여준다.
눈에 걸리는 상태(승인 대기 = 호박색, 오류 = 붉은 주황색)는 주변 시야로도 알아챌 수 있게 한다.

## 사용자

- 로컬에서 AI 에이전트(향후 Hermes Agent 등)를 돌리는 개발자.
- 에이전트를 띄워두고 다른 일을 하면서 상태만 가끔 확인하고 싶은 사람.

## 제품 원칙

1. **관찰만 한다.** 에이전트를 조작하지 않는다. 승인 버튼도, 명령 입력창도 없다.
2. **사실만 보여준다.** 실제 이벤트가 말한 것만 표시한다. 진행률 바, 예상 시간, "아마 ~하는 중" 같은 추측은 없다.
3. **비밀을 모른다.** 프롬프트·코드·경로·명령·키 같은 내용은 애초에 받지도 저장하지도 않는다.
4. **방해하지 않는다.** 작고, 대부분 투명하고, 움직임을 줄일 수 있다.
5. **Provider 중립.** 특정 에이전트에 묶이지 않는 이벤트 규격을 쓰고, provider별 변환은 adapter가 맡는다.
6. **데모는 데모라고 말한다.** 가짜 데이터로 동작할 때는 항상 DEMO 배지를 보인다.

## 범위

### 첫 vertical slice (현재 목표)

- Tauri 2 앱 스캐폴딩, 투명 창
- 직접 만든 SVG 아이소메트릭 픽셀 미니룸과 헤르메스·친구 스프라이트
- 결정적 demo 이벤트 소스와 순수 event → visual state 리듀서
- `idle → thinking → coding → terminal → success → idle` 시나리오
- DEMO 배지, reduced-motion, 기본 테스트

### MVP (vertical slice 이후)

- 11개 상태 전부의 포즈·애니메이션·텍스트와 전체 상태 데모 투어
- 활동 패널, 크기·투명도·위에 띄우기·드래그
- 미니룸의 일상(대기 중 샤워·밥·TV·친구 초대 등)과 친구 초대 버튼
- Hermes Agent adapter (별도 ADR 후)

### 하지 않는 것 (Non-goals)

- 에이전트 제어, 권한 승인, 명령 실행
- 대화 내용·reasoning·파일 diff 뷰어
- 토큰 사용량, 비용, 진행률 대시보드
- 여러 에이전트 동시 모니터링 (향후 검토)
- Windows/Linux 정식 지원 (macOS 우선)

## 성공 신호

- 사용자가 창을 전환하지 않고도 "일하는 중 / 승인 대기 / 끝남 / 오류"를 1초 안에 구분한다.
- 데모 모드와 실제 모드를 혼동하지 않는다.
- 보안 리뷰에서 민감 데이터가 UI·로그·저장소에 남는 경로가 발견되지 않는다.
