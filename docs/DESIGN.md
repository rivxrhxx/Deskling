# DESIGN — Deskling 시각 디자인

## 1. 방향

- **헤르메스의 사생활을 엿보는 미니룸.** 바탕화면에 박힌 작은 아이소메트릭 픽셀 방에서
  헤르메스가 일하고, 씻고, 밥 먹고, 친구를 부르며 지낸다(ADR-019, ADR-020).
- **SaaS 대시보드 카드가 아니다.** 둥근 흰 카드, 그림자 박스, 차트 같은 요소를 쓰지 않는다.
- 창의 대부분은 **투명**하다. 보이는 것은 방 한 칸(바닥판 + 두 벽)과 작은 말풍선뿐이다.
- 밝은 크림색 벽, 나무 마루, 파스텔 소품. 이 장르의 분위기만 빌리고, 특정 게임·서비스의 그림·배치·캐릭터는 베끼지 않는다.
- 헤르메스와 친구는 이 앱 전용 원본 픽셀 스프라이트다(§3.2).
- 모든 그래픽은 직접 작성한 SVG primitive와 ASCII 픽셀 맵. 외부 이미지·폰트·아이콘 팩을 쓰지 않는다.

규칙: 호박색은 승인 대기에서만, 붉은 주황은 오류에서만 쓴다. 화남은 머리 위 작은 이모트로만 쓴다.
상태는 색만으로 구분하지 않는다. 헤르메스의 행동·이모트·모니터 화면·말풍선 글자가 함께 바뀐다.

## 3. 장면 구성 — 미니룸 (SVG viewBox `0 0 480 320`, ADR-019)

### 3.1 방 (아이소메트릭 2:1, 타일 32×16, 9×9 바닥)

```
            [상태 말풍선: 아이콘 + 텍스트]          ← HTML, role=status
 [DEMO]               ╱╲
     왼쪽 벽 →      ╱    ╲      ← 오른쪽 벽
  창문·책장·소파   ╱ 침대 책상 ╲   냉장고·샤워 부스·문
                  ╲  러그  식탁 ╱
                   ╲   화분   ╱    바닥: 나무 마루, 가운데 통로(hub)
                    ╲______╱
```

- 좌표: 타일 `(x, y)` → 화면 `(240 + (x−y)·16, 150 + (x+y)·8)`. 높이 z는 화면에서 위로 1:1.
- 벽: 크림색 + 위쪽 파스텔 무늬 띠 + 걸레받이. 높이 112. 바닥: 나무 마루 줄 + 두께 10의 옆면.
- 가구는 아이소메트릭 상자(윗면 밝게, 왼쪽 면 중간, 오른쪽 면 어둡게) + 픽셀 장식.
  - 침대 — 왼쪽 안쪽, 머리판이 왼쪽 벽에 붙음.
  - 책상·모니터·키보드·의자 — 오른쪽 벽 앞. 모니터에 상태 화면(§4)이 뜬다.
  - 냉장고(민트), 유리 샤워 부스(타일 벽, 옆으로 걷힌 커튼), 문 — 오른쪽 벽.
  - 창문(낮 하늘/밤하늘, 분홍 커튼), 책장, 소파(방 쪽을 봄) — 왼쪽 벽.
  - 낮은 TV 장(소파를 봄), 다리 달린 식탁과 의자, 화분, 가운데 러그 — 바닥.
- 깊이: 가구와 사람을 앞쪽 깊이(x+y)로 정렬해 앞에 있는 것이 나중에 그려진다.
  가구를 쓰는 사람은 그 가구 그룹 안에 그린다.
  - 침대에서 자면 머리가 베개 위, 그 위에 이불.
  - 샤워 중이면 유리 뒤.
  - 소파에 앉으면 팔걸이 앞.
- 오프라인이면 방 전체에 밤 오버레이를 덮고 창밖이 밤하늘이 된다. 친구가 문 근처를 지날 때 문이 열린다.

### 3.2 헤르메스와 친구 (원본 픽셀 스프라이트)

- 헤르메스: 날개 달린 파란 모자, 갈색 머리, 흰 셔츠, 보라 목도리, 파란 반바지, 빨간 운동화. 2~3등신 치비. 12×16 픽셀.
- 포즈:
  - 서기(앞/뒤), 걷기 2프레임(앞/뒤);
  - 뒤돌아 앉기와 타이핑, 앞으로 앉기;
  - 잠, 샤워(머리 + 거품), 손 흔들기, 두 팔 위로, 머리 감싸기, 책 읽기, 물주기.
- 왼쪽을 향하면 좌우 반전한다.
- 친구 두 명은 같은 몸에 다른 머리·옷 색이다. 손님일 때는 소파에, 도우미일 때는 옆 탁자 노트북 앞에 앉는다.
- 이모트: 머리 위 픽셀 기호 하나. 우선순위는 다음과 같다.
  1. 사용자의 돌보기
  2. 사용자가 필요한 상태(호박색 ! / 붉은 주황 !)
  3. 잠(z)
  4. 화남(김 > 핏줄 > 땀)과 에너지 바닥(배터리) — 순서는 김, 핏줄, 배터리, 땀
  5. 행동별 이모트. 걷는 동안에는 행동별 이모트를 생략한다.

### 4.1 에너지와 화남 (ADR-016)

시각 상태 위에 겹쳐지는 분위기 표시. 숫자는 그리지 않는다(숫자는 활동 패널).

| 값 | 단계 | 장면 표현 |
| --- | --- | --- |
| 에너지 | full | 표시 없음, 걷기 보통 |
| 에너지 | ok | 책상에 빈 에너지 캔 1개 |
| 에너지 | low | 빈 캔 2개, 걷기 느려짐, 일상에서 낮잠·간식이 잦아짐 |
| 에너지 | empty | 빈 캔 3개, 배터리 이모트, 더 느리게 걸음 |
| 화남 | calm | 표시 없음 |
| 화남 | annoyed | 땀방울 이모트 |
| 화남 | angry | 장미색 핏줄 이모트 |
| 화남 | furious | 머리 위 김 이모트 |

| --- | --- | --- |

### 4.3 일상 (idle에서만, ADR-020)

헤르메스가 스스로 고른다(시드 고정 PRNG, 직전 일상은 피함). 시간은 도착한 뒤부터 잰다.

| 일상 | 장소 | 시간 | 이모트 |
| --- | --- | --- | --- |
| `shower` | `shower` 유리 부스 안, 물줄기 | 9초 | `bubbles` |
| `eat` | `table` 식탁 의자, 접시 | 7초 | `note` |
| `watch-tv` | `sofa` TV가 켜짐 | 10초 | `note` |
| `read` | `bookshelf` 책장 앞 | 8초 | 없음 |
| `look-outside` | `window` 창문 앞 | 6초 | `moon` |
| `stretch` | `stretch` 방 앞쪽 | 4초 | `sparkle` |
| `water-plant` | `plant` 화분 옆 | 5초 | `water` |
| `nap` | `bed` 이불 덮고 | 10초 | `zzz` |
| `fridge` | `fridge` 냉장고 앞 | 4초 | 없음 |
| `host-friend` | `sofa` 친구가 문으로 들어와 옆에 앉음 | 14초 | `note` |

- 에너지 low/empty면 nap·eat·fridge 가중치를 높이고 걷기 속도를 줄인다.
- 친구는 문 밖에서 걸어 들어와 소파에 앉았다가 시간이 되면 문으로 나간다. 패널의 "친구 초대"로도 부를 수 있다(오프라인이거나 이미 손님이 있으면 비활성).
- 위임 중에는 친구가 도우미로 와서 책상 옆 탁자의 노트북 앞에 앉고, 위임이 끝나면 나간다.

## 5. UI 요소

- **상태 말풍선**: 장면 위쪽 중앙. 작은 어두운 반투명 말풍선, 톤 색 아이콘 + 라벨. 항상 실제 에이전트 상태를 보여준다.
- **DEMO 배지**: 좌상단 고정. 보라 테두리 알약, 굵은 대문자 `DEMO`. 데모 모드에서 숨길 수 없다.
- **활동 패널**: 어두운 유리 패널.
  - 맨 위 펫 영역, 에너지·컨텍스트 숫자, 고정폭 시각 + 짧은 문구 목록, 데모 시나리오 선택이 들어간다.
- **툴바**: 아래쪽, hover/focus-within 때만 나타나는 작은 버튼 줄
  (크기 S/M/L, 투명도 슬라이더, 위에 띄우기, 모션, 닫기). 모든 버튼에 `aria-label`.

## 6. 모션

- 걷기·타이핑·점프는 300ms 틱(`LIFE_TICK_MS`)의 2프레임 픽셀 애니메이션이다.
  - 걷는 속도는 초당 1.8타일(에너지 low 1.2, empty 0.9).
- 반복 애니메이션은 작게 한다: 이모트 2px 흔들림, 샤워 물방울, TV 깜빡임, 줄 조명, 모니터 커서.
  화면 전체를 흔들거나 번쩍이지 않는다.
- 상태 전환은 180ms 크로스페이드 정도로 짧게.
- `[data-motion="reduced"]`이면 모든 animation/transition을 끄고, 헤르메스는 걷지 않고 **순간 이동**한다.
  프레임도 0에 고정한다. 정지 상태에서도 행동·이모트·말풍선이 남는다.
- `data-motion`은 시스템 `prefers-reduced-motion`과 앱 설정(`시스템/줄이기/전체`)을 결합해 정한다.

## 7. 타이포그래피와 크기

- 시스템 폰트(`-apple-system`, `SF Pro`)만 사용. 외부 폰트 없음.
- 루트 font-size를 창 너비에 비례(`100vw / 48`)로 두고 rem을 써서 S/M/L 크기 변경 시 전체가 같이 커진다.
- 기본(M) 창: 480×340. 방은 창 아래쪽에 100vw 너비로 붙는다. S = 0.8배, L = 1.3배.
- 픽셀 스프라이트는 `shape-rendering: crispEdges`로 그려 흐려지지 않는다.

## 8. 접근성

- 상태 텍스트는 `role="status"` + `aria-live="polite"`.
- 장면 SVG는 `role="img"`, 이름 "헤르메스의 방 — {상태 라벨}".
- 장면 위에 투명한 HTML `button`("최근 활동 보기")이 헤르메스를 따라다닌다. Enter/Space로 패널을 연다.
- 패널은 `role="dialog"`, `aria-label="최근 활동"`, Esc로 닫힘.
- 텍스트 대비는 어두운 유리 배경 위 `--text` 기준 4.5:1 이상.
