# DESIGN — Deskling 시각 디자인

## 1. 방향

- **SaaS 대시보드 카드가 아니다.** 둥근 흰 카드, 그림자 박스, 차트 같은 요소를 쓰지 않는다.
- 창의 대부분은 **투명**하다. 보이는 것은 작은 디오라마(바닥판 + 뒷벽 조각)와 그 위의 사물뿐이다.
- 밤에 모니터만 켜둔 **어두운 미니어처 개발자 작업실**. 빛의 주인공은 모니터의 차가운 빛이다.
- 캐릭터는 이 앱 전용 원본 디자인: 둥근 젤리빈 몸, 점 눈, 상태색으로 빛나는 더듬이 전구, 절제된 보라색 목도리.
- 모든 그래픽은 직접 작성한 SVG/CSS primitive. 외부 이미지·폰트·아이콘 팩을 쓰지 않는다.

## 3. 장면 구성 (SVG viewBox `0 0 400 260`, ADR-017)

```
               [상태 말풍선: 아이콘 + 텍스트]                ← HTML, role=status
 [DEMO]
     ┌──────────────────── 뒷벽 ─────────────────────┐
     │  [창문: 밤하늘]                (●) 램프  [선반] │
     │                              ┌──모니터──┐       │
     │ ▭베개 ▒▒이불▒▒   의자 ●       │ 화면     │ 캔 머그│
     │ ════ 침대 ════   캐릭터       └──┬───────┘       │
     │                         ══════ 책상 ═══════  ✿  │
     └────────────────────────────────────────────────┘
   ╱───────────────── 바닥판(디오라마) ──────────────────╲
```

- 방을 들여다보는 디오라마. 왼쪽은 쉬는 공간(침대), 오른쪽은 일하는 공간(책상·모니터).
- 바닥판: 살짝 원근감 있는 사다리꼴 윗면 + 어두운 옆면 + 아래 그림자 타원.
- 모니터 뒤에는 상태 톤 색의 방사형 빛(glow)이 깔린다.
- 작업 상태에서 캐릭터는 책상 의자에 앉는다. 대기·오프라인이면 침대로 가고 의자는 비어 있다.
- 위치가 바뀌면 걸어가는 짧은 애니메이션(약 0.6초)을 보여준다.

### 4.1 에너지와 화남 (ADR-016)

시각 상태 위에 겹쳐지는 분위기 표시. 숫자는 그리지 않는다(숫자는 활동 패널).

| 값 | 단계 | 장면 표현 |
| --- | --- | --- |
| 에너지 | full | 표시 없음 |
| 에너지 | ok | 책상에 빈 에너지 캔 1개 |
| 에너지 | low | 빈 캔 2개, 눈꺼풀 반쯤 내려옴, 더듬이 전구 흐려짐 |
| 에너지 | empty | 빈 캔 3개, 눈꺼풀 많이 내려옴, 전구 거의 꺼짐, 움직임 느려짐 |
| 화남 | calm | 표시 없음 |
| 화남 | annoyed | 일자 눈썹 |
| 화남 | angry | 찡그린 눈썹 + 장미색 핏줄 표시 |
| 화남 | furious | 찡그린 눈썹 + 핏줄 표시 + 머리 위 김 + 볼 붉어짐 |

`unknown`(보고 없음)은 아무것도 그리지 않는다. 오프라인(잠)에서는 분위기 표시를 숨긴다.

## 5. UI 요소

- **상태 말풍선**: 장면 위쪽 중앙. 작은 어두운 반투명 말풍선, 톤 색 아이콘 + 라벨.
- **DEMO 배지**: 좌상단 고정. 보라 테두리 알약, 굵은 대문자 `DEMO`. 데모 모드에서 숨길 수 없다.
- **활동 패널**: 벽에 걸린 작은 CRT 로그 화면 느낌. 어두운 유리, 고정폭 시각 + 짧은 문구 목록. 닫기 버튼.
- **툴바**: 바닥판 아래쪽, hover/focus-within 때만 나타나는 작은 아이콘 버튼 줄
  (크기 S/M/L, 투명도 슬라이더, 항상 위 핀, 모션, 닫기). 모든 버튼에 `aria-label`.

## 6. 모션

- 상태 애니메이션은 0.8~3초 주기의 작은 반복. 화면 전체를 흔들거나 번쩍이지 않는다(오류 떨림은 1px 이내).
- 상태 전환은 180ms 크로스페이드 정도로 짧게.
- `[data-motion="reduced"]`이면 모든 animation/transition을 끈다. 정지 상태에서도 포즈·아이콘·텍스트가 남는다.
- `data-motion`은 시스템 `prefers-reduced-motion`과 앱 설정(`시스템/줄이기/전체`)을 결합해 정한다.

## 7. 타이포그래피와 크기

- 시스템 폰트(`-apple-system`, `SF Pro`)만 사용. 외부 폰트 없음.
- 루트 font-size를 창 너비에 비례(`100vw / 40`)로 두고 rem을 써서 S/M/L 크기 변경 시 전체가 같이 커진다.
- 기본(M) 창: 400×280(ADR-017). S = 0.8배, L = 1.3배.

## 8. 접근성

- 상태 텍스트는 `role="status"` + `aria-live="polite"`.
- 캐릭터는 `role="button"`, `tabIndex=0`, `aria-label="최근 활동 보기"`, Enter/Space로 패널 열기.
- 패널은 `role="dialog"`, `aria-label="최근 활동"`, Esc로 닫힘.
- 텍스트 대비는 어두운 배경 위 `--text` 기준 4.5:1 이상.
